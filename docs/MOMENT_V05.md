# v0.5 moment — the shell heard continuity

This acceptance run uses the 20,640-parameter Q12 body produced by the earlier
1000-step learning experiment. The body is not a deterministic fixture: its
training loss fell from 4.6406 to 0.4187 and it learned local Dracula-shaped
continuations. That experiment used the temporary ABI-compatible forge recorded
with the earlier moment, not the pinned upstream checkout. This document therefore
proves the v0.5 inference and state loop; it does **not** relabel the old training
run as an upstream-Notorch acceptance.

All commands below were executed twice: once by `bashformer.sh`, whose inference
path is GNU Bash builtins only, and once by the independent fixed-point C oracle.
Generated bytes, traces, and serialized state matched exactly.

## Connectedness is a live distribution

Probe prompt:

```text
The blood was warm. The night was still. The 
```

The first two sentences were committed to the history; the unfinished third
sentence attended over both. The final pre-decode trace was:

```text
TRACE spa conn=2048 temp=2457 current=5 history=2 sentences=2 alpha=3482 strength=3277
```

In Q12, connectedness 2048 is 0.5. With strength 3277 (~0.8), the resulting SPA
temperature multiplier is 2457 (~0.6). Bash and C selected token ID 77 and agreed
on every preceding layer and field trace.

## Surprise changes how strongly experience is written

The same learned body observed the same sequence `AB` once in flat mode and once
with prophecy debt 5:

```text
flat gain             4096   # 1.0x
flat edge 34 -> 35    4096
flat total edge mass  8192

debt gain             6144   # 1.5x
debt edge 34 -> 35    6144
debt total edge mass 12288
```

The chosen token was identical. Only the field's debt changed the magnitude of
the Hebbian write, using:

```text
gain = 1 + debt / (debt + 5)
```

## Two processes, one continuing field

Two independent Bash processes shared one BFSOMA3. The first started SPA and
debt-gated plasticity with debt 3:

```text
prompt: The blood was warm. The night was 
output: still. dor as wa
```

The first process exited. A second process received no `--spa` or `--plasticity`
flags; it resumed both from the soma:

```text
prompt: Night. The 
output: she ward are are
```

After the second process the state contained:

```text
M DEBT_Q 21407
M VELOCITY nomove
M FIELD_STEPS 32
M RECOVERIES 1
M PLASTICITY debt
M PLASTICITY_UPDATES 77
M PLASTICITY_LAST_GAIN_Q 6189
M SPA_HISTORY_N 3
M SPA_SENTENCES 3
M SPA_LAST_CONN_Q 1380
M SPA_LAST_TEMP_Q 2992
```

The accumulated debt crossed the recovery threshold, so the inherited velocity
became `nomove`. Sentence vectors, the unfinished sentence, H-term edges, debt,
recovery, and plasticity all survived process death. A matching pair of C
processes produced identical outputs, traces, intermediate soma after session 1,
and final BFSOMA3 after session 2.

## What this proves

- learned BFW1 weights remain executable after the forge is gone;
- sentence embeddings and connectedness alter a learned body's sampled path;
- SPA history and unfinished sentence state survive process boundaries;
- prophecy debt modulates Hebbian write strength rather than merely affecting sampling;
- recovery, SPA, H-term memory, laws, and plasticity coexist in one causal loop;
- Bash and an independent C implementation agree exactly on that loop.

## What remains open in this environment

The pinned upstream Notorch checkout cannot be downloaded in this container: it
has no outbound GitHub/DNS path, and the GitHub connector can inspect repository
content but cannot materialize the complete tree into the build filesystem. The
repository's honest acceptance gate remains:

```bash
make bootstrap
make doctor
make upstream-smoke
```

or, on an air-gapped machine with a verified checkout:

```bash
NOTORCH_SOURCE=/path/to/notorch make bootstrap
make doctor
make upstream-smoke
```
