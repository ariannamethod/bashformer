# bashformer

**v0.3.0 — the shell learned to remember.**

> notorch asks whether you need PyTorch.  
> bashformer asks whether you need C at inference time.

**Bashformer** is a decoder-only Transformer trained by
[notorch](https://github.com/ariannamethod/notorch) and executed by GNU Bash.
The runtime performs embeddings, RMSNorm, GQA, RoPE, causal softmax, SwiGLU,
residual connections, the tied language-model head, and autoregressive decoding
with Bash integer arithmetic and indexed arrays. An optional Arianna Method field can
modulate logits, sampling temperature, and now a persistent Hebbian co-occurrence memory
without adding a runtime dependency.

No `awk`. No `bc`. No Python. No hidden C helper. No vendored framework.

## The split

| Stage | Engine |
|---|---|
| Training and export | installed upstream **notorch** |
| Weight format | BFW1, checked ASCII fixed-point tensors |
| Production inference | **GNU Bash builtins only** |
| Correctness oracle | independent integer C reference, tests only |

Notorch is installed into `${BASHFORMER_PREFIX:-$HOME/.local}` from the pinned
commit in `requirements.txt`. Its source is fetched into a temporary cache,
built, installed, and deleted. The repository contains no frozen `notorch.c`. Backend
selection prefers Accelerate/OpenBLAS, then Notorch's own AVX2+FMA SIMD path, then scalar.
See [`docs/NOTORCH.md`](docs/NOTORCH.md).

## Architecture v0

The training forge in `src/train.c` builds a deliberately tiny Llama-3-shaped
character model for Bram Stoker's *Dracula*:

```text
vocab       96 bytes (newline, space, printable ASCII)
context     64
d_model     32
layers      2
q_heads     4
kv_heads    1     # grouped-query attention
head_dim    8
ffn         64
rope theta  500,000
parameters  20,640
tied head   yes
```

Each block is:

```text
RMSNorm -> GQA(Q,K,V + RoPE) -> projection -> residual
RMSNorm -> SwiGLU -> projection -> residual
final RMSNorm -> tied WTE head
```

The Bash export uses signed Q12 fixed point. `EXP_NEG` and `SIGMOID` lookup
tables are generated by the exporter; RoPE sine/cosine values are also exported,
so inference never asks the shell to calculate `exp`, `sin`, `cos`, or `sqrt`
(the one square root it needs, RMSNorm, is integer Newton iteration).

## Prove the arithmetic before training

```bash
make test
```

This generates deterministic fixture weights, runs several prompts through both
the C integer oracle and `bashformer.sh`, and compares:

- Q and K after RoPE;
- causal attention output;
- post-block hidden state;
- final logits;
- greedy next-token ID.

The comparison is exact, checksum for checksum. A second oracle suite applies DESTINY,
PAIN, FOCUS/SPREAD, the field gate, and all five velocity modes, then compares transformed
logits and deterministic sampled text byte-for-byte. The test also invokes Bashformer
with an intentionally empty `PATH`; inference still succeeds, proving that the
runtime does not quietly call an external utility. Separate tests corrupt BFW1
records, exercise pinned dependency install/reuse/failure cleanup, and run the
complete trainer/checkpoint/export path against a notorch ABI contract stub. The stateful
suite also compares the Hebbian H-term and serialized `BFSOMA1` memory byte-for-byte
against the independent C runtime.

## Train on Dracula

```bash
make bootstrap       # install pinned upstream Notorch; auto-select acceleration
make doctor          # link/run the exact GQA/RoPE/SwiGLU/Chuck API contract
make corpus          # fetch dracula.txt from ariannamethod/nanoGPT-notorch
make train            # train, checkpoint, and export weights/bashformer.bfw
```

The corpus URL is pinned to an immutable `nanoGPT-notorch` commit. After
bootstrap, a short wiring run is available without downloading Dracula:

```bash
make quick            # 20 steps on data/tiny.txt; pipeline test, not a quality run
```

Or control the forge directly:

```bash
./build/bashformer-train \
  --corpus data/dracula.txt \
  --steps 20000 \
  --lr 3e-4 \
  --out weights/bashformer
```

Resume from `weights/bashformer.bin`:

```bash
./build/bashformer-train --resume --corpus data/dracula.txt --out weights/bashformer
```

Probe the float Notorch checkpoint and inspect its top five next-token choices:

```bash
./build/bashformer-train \
  --probe weights/bashformer.bin 'The blood was '
```

## Speak through Bash

Greedy generation:

```bash
./bashformer.sh \
  --weights weights/bashformer.bfw \
  --prompt 'The blood was ' \
  --tokens 32
```

Fixed-point sampling without `bc`, reproducible through the built-in xorshift32 sampler:

```bash
./bashformer.sh --prompt 'CHAPTER I' --tokens 32 --temperature 0.8 --seed 42
```

Inspect the next token or the integer pipeline:

```bash
./bashformer.sh --prompt 'Mina ' --next-id
./bashformer.sh --prompt 'Mina ' --next-hex
./bashformer.sh --prompt 'Mina ' --next-id --trace
```

## Why `bashformer`, not `bashformer-notorch`

Notorch is the forge. Bashformer is the organism. The trained model must remain a
real Transformer after the forge is removed from the room.

## Method physics — stateless + living memory

The Method layer remains opt-in. The formulas and state are ported into
Q12 Bash directly; production inference does **not** call `aml`, link `libaml.a`, or start
another process.

```bash
./bashformer.sh \
  --weights weights/bashformer.bfw \
  --prompt 'The blood was ' \
  --tokens 32 \
  --temperature 0.8 \
  --seed 42 \
  --velocity run \
  --prophecy 12 \
  --destiny 0.35 \
  --pain 0.20 \
  --focus 0.80 \
  --spread 0.10
```

The implemented order is:

```text
Transformer logits
  -> Hebbian H (optional, stateful)
  -> DESTINY × PROPHECY
  -> PAIN
  -> ATTEND_FOCUS / ATTEND_SPREAD
  -> temperature × VELOCITY
  -> seeded fixed-point sampling
```

`--velocity` accepts `raw`, `nomove`, `walk`, `run`, or `breathe`. `--hebbian` enables
live co-occurrence; `--soma FILE` makes that memory persistent in checked `BFSOMA1`, and
`--learn off` applies existing memory without changing it. Any Method option
enables the field; `--field off` is an explicit ablation gate and restores the exact
vanilla trace. Coefficients default to identity, so `--method` alone does not secretly
move logits.

```bash
make test                    # includes tests/method.sh
./bashformer.sh --help       # complete Method CLI
```

`requirements.method.txt` still pins `ariannamethod.ai`, but only as an optional
development oracle:

```bash
./bootstrap.sh requirements.method.txt
```

The first stateful contamination layer has landed: Hebbian co-occurrence plus persistent
soma. Next are the entropy/resonance laws and prophecy debt/velocity recovery, followed by
seasonal and identity mechanisms. Each enters behind an ablation gate after independent
C/Bash parity.

The full graph and fixed-point contract are in
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
